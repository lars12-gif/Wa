# 🌋 VOLCANO v2 — Fast Group Protection

بوت حماية لمجموعات WhatsApp باستخدام JavaScript + Baileys.

## 🚨 ترتيب الاستجابة

عند اكتشاف بطاقة جهة اتصال مشبوهة في مجموعة منصبة، يحافظ مسار الحماية على الترتيب المطلوب:

**1. طرد المرسل → 2. حذف الرسالة → 3. قفل المجموعة**

تُرسل العمليات الحرجة بأقل قدر ممكن من الانتظار، مع منع تكرار معالجة نفس الرسالة.

> لا يمكن ضمان أن WhatsApp سينفذ أي عملية قبل تفاعل مستخدم آخر في كل حالة؛ التنفيذ الفعلي يعتمد على زمن وصول الأحداث وصلاحيات الحساب وخدمة WhatsApp.

## 🛡️ الحماية

- Contact Guard لرسائل `contactMessage` و `contactsArrayMessage`.
- Deduplication لمنع معالجة نفس الرسالة أكثر من مرة.
- Emergency Lock مؤقت أثناء الهجوم.
- معالجة الهجمات المتتابعة.
- رسالة دفاع تلقائية مع صورة Volcano.
- لا يعمل Security Engine إلا في المجموعات التي تم تنصيبها.
- لا يحاول البوت طرد المشرفين.
- يتطلب الحساب صلاحية مشرف لتنفيذ الطرد والحذف والقفل.

## 🔐 Pairing Code — 3 دقائق

- لا يوجد QR.
- يتم طلب Pairing Code فقط بعد أن تبدأ جلسة Baileys الاتصال، لتجنب خطأ `428 Connection Closed` الناتج عن طلب الرمز قبل جاهزية الـ WebSocket.
- توجد مهلة **180 ثانية (3 دقائق)** للجلسة غير المرتبطة.
- إذا لم يحدث الربط خلال المدة، تُغلق جلسة الربط وتُنظف بيانات المصادقة المؤقتة.
- لا تتم إعادة محاولة الربط تلقائياً بعد انتهاء المهلة؛ أعد تشغيل الخدمة عندما تريد بدء جلسة ربط جديدة.
- بعد نجاح الربط، ينتهي مؤقت الثلاث دقائق ولا يؤثر على الجلسة الدائمة.

## إصلاح مشكلة 428

إذا ظهر:

```text
Error: Connection Closed
statusCode: 428
message: Connection Closed
at ... requestPairingCode
```

فالسبب المعتاد هو استدعاء `requestPairingCode()` قبل أن تصبح جلسة WebSocket جاهزة. Volcano v2.1 ينتظر حدث `connection.update` (`connecting` أو `qr`) ثم ينتظر 2.5 ثانية قبل طلب الرمز، مع منع تكرار الطلب.

## الأوامر

`.تنصيب` — تفعيل الحماية للمجموعة الحالية.

`.إلغاء` أو `.الغاء` — إيقاف الحماية.

`.حالة` — عرض حالة الحماية.

`.مساعدة` — عرض الأوامر.

## التشغيل

```bash
npm install
cp .env.example .env
npm start
```

ضع `PHONE_NUMBER` بدون `+` أو مسافات، مع رمز الدولة.

## الاستضافة

ارفع المشروع إلى GitHub، ثم استخدم Node.js 20+ أو Docker.

يجب توفير Persistent Storage لمجلد `auth/` حتى لا تضيع جلسة WhatsApp بعد إعادة تشغيل الخدمة.

**لا ترفع `auth/` إلى GitHub.**

## الصلاحيات

يجب أن يكون حساب Volcano مشرفاً حتى يستطيع الطرد والحذف والقفل.

## ملاحظة إنتاجية

`useMultiFileAuthState` مستخدم هنا لتسهيل النشر، لكن توثيق Baileys يحذر من استخدامه كحل تخزين إنتاجي نهائي بسبب عمليات I/O الكثيرة. عند الانتقال إلى تشغيل واسع، يمكن نقل حالة المصادقة إلى مخزن مخصص/قاعدة بيانات.
